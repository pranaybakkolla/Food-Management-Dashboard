# Food Management Dashboard

A full-stack application designed to manage food items efficiently. Users can view, add, and delete food items from the dashboard.

## Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS
* **Backend:** Node.js, Express
* **Database:** MySQL

## Features
* View a list of all food items.
* Add new food items to the system.
* Delete existing items.

## How to Run Locally
### Prerequisites
* Node.js installed on your machine.
* MySQL Server installed and running.
